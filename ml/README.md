# ML Modülü

Veri seti hazırlama, keşifsel veri analizi (EDA), baseline model, BERTurk ince ayarı ve zamana göre ayrılmış (temporal split) değerlendirme scriptleri burada yer alır.

> **KVKK Notu:** `data/raw/` klasörü `.gitignore` ile hariç tutulmuştur. Kişisel veri içeren ham mesajları asla repoya eklemeyin.
